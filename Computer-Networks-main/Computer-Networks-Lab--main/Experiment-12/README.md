# Experiment 12: Exploring Network Simulation and Analysis Tools

## Aim
To explore various network simulation, emulation, security and packet analysis tools used in computer networks.

## Tools Studied

1. **NS-3:** A discrete-event network simulator used for research and network protocol evaluation.
2. **OMNeT++:** A simulation framework for modeling communication networks and distributed systems.
3. **GNS3:** A network emulator used to create and test virtual network topologies.
4. **pfSense:** An open-source firewall and routing platform.
5. **Wireshark:** A network protocol analyzer used to capture and inspect network packets.
6. **SDN:** Software Defined Networking separates the control plane from the data plane.

## Requirements
- Windows computer
- Internet connection
- Wireshark
- Npcap

## Theory
Network simulation and analysis tools help network administrators, researchers and developers understand network behavior, test protocols, troubleshoot connectivity and analyze traffic.

Wireshark captures packets from network interfaces and displays protocol information for analysis.

## Procedure

1. Download and install Wireshark from its official website.
2. Open Wireshark and select an active network interface.
3. Start packet capture.
4. Open Windows Command Prompt.
5. Generate ICMP traffic using:

```bash
ping 8.8.8.8
```

6. Return to Wireshark.
7. Apply the display filter:

```text
icmp
```

8. Observe the ICMP Echo Request and Echo Reply packets.
9. Select a packet and inspect its Ethernet, IP and ICMP protocol details.

## Observations
- Wireshark captures packets transmitted over the selected network interface.
- ICMP Echo Request packets are generated by the ping command.
- ICMP Echo Reply packets indicate responses from the destination.
- Packet details show source and destination addresses and protocol information.

## Result
Studied various network simulation and analysis tools and successfully captured and analyzed ICMP packets using Wireshark.
